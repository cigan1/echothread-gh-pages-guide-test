# EchoThread GitHub Pages guide test

A throwaway fixture that follows https://echothread.io/docs/guides/github-pages/
exactly: one `_includes/echothread.html`, one `_layouts/post.html`, and two posts.

The `window.ECHOTHREAD_API_URL` line in `_layouts/default.html` points the widget at a
local development API and is present only so the guide can be verified end to end.
